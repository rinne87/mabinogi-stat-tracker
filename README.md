# 마비노기 모바일 스탯 매니저 (직업별 목표 기준표 & 내 캐릭터 비교)

서버 없이 **100% 정적 웹(GitHub Pages 완벽 호환)**으로 동작하는 마비노기 모바일 캐릭터 스탯 비교 및 관리 웹앱입니다.

## 주요 기능
1. **계층형 캐릭터 관리 (`서버 > 캐릭터 > 클래스 세팅 슬롯`)**
   - 기본 샘플: `던컨 > 로산나 > 석궁사수` 및 실제 스크린샷 스탯 21종 탑재
   - 한 캐릭터 안에 여러 직업/세팅 슬롯(예: 본직업 석궁사수, 부직업 음유시인 등) 추가 가능
2. **직업별 목표 스탯 기준표 사전**
   - 직업별로 **필수 목표치(커트라인)**, **권장 고점 수치**, **남은 스탯 몰빵 항목**, **공략 메모**를 자유롭게 설정
   - 새 직업이 출시되거나 시즌 메타가 바뀌어도 언제든 직접 직업을 추가/수정 가능
3. **부족한 스탯 실시간 진단 대시보드**
   - 인게임 스탯 창과 동일한 2열 배치 UI에서 숫자를 수정하면 즉시 우측에서 부족분(`-`)과 달성률(`%`)을 계산하여 표시
4. **스크린샷 OCR 자동 입력 (`Ctrl + V` 붙여넣기 지원)**
   - 스탯 창 캡처 이미지를 붙여넣거나 업로드하면 브라우저 내장 OCR(`Tesseract.js`)로 숫자를 자동 추출
5. **브라우저 자동 저장(`localStorage`) 및 JSON 파일 백업/복원**

## GitHub Pages 배포 방법
1. GitHub에서 새 저장소(Repository)를 생성합니다.
2. 이 폴더의 `index.html`, `app.js`, `README.md` 파일을 업로드(Push)합니다.
3. 저장소의 **Settings > Pages > Build and deployment**에서 Branch를 `main`으로 선택하고 Save를 누르면 `https://아이디.github.io/저장소명/` 주소로 언제 어디서나 접속할 수 있습니다.
